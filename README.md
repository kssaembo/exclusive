# 독점게임 학급 에디션 v2.2

교사가 전체 상태를 관리하고, 학생은 2~3대의 거래소 태블릿에서 비공개 맞교환을 진행하는 단일 게임 웹서비스입니다. 기존 WebRTC 검증 화면을 실제 수업 운영 흐름에 맞춰 `메인 → 설명 → 사전 설정 → 교사 운영 + 학생 전광판 → 거래소` 구조로 재구성했습니다.

## 학급용 재구성 규칙

- 플레이어는 6~15명이며, 한 줄에 한 명씩 이름을 등록합니다. 각 플레이어는 8장씩 받습니다.
- 플레이어 수와 같은 수의 자원 종류를 사용합니다. 각 자원은 7~8장, 폭탄은 전체 카드의 약 7.8%인 4~9장으로 자동 조정합니다.
- 전체 카드 수는 항상 `플레이어 수 × 8장`이며 미배부 카드는 없습니다.
- 두 플레이어가 거래소에서 각자 비공개로 카드를 선택하고 같은 장수끼리만 교환합니다.
- 거래 직후 한 종류의 자원 또는 폭탄 전량 보유를 Host가 자동 판정하고 즉시 게임을 종료합니다.
- 해당 게임의 폭탄을 모두 모으면 `폭탄 역독점`으로 즉시 승리합니다.
- 제한시간 종료 시 가장 높은 자원 완성률을 100점으로 환산하고 폭탄 1장당 15점을 감점해 최종 순위를 정합니다.
- 단일 게임에 의미가 없는 가넷, 생명의 징표, 탈락후보, 폭탄 해체 비용은 사용하지 않습니다.

폭탄은 PIT의 곰 카드처럼 다른 플레이어에게 넘기고 싶은 위험 카드이면서, 해당 게임의 폭탄 4~9장을 모두 모으면 역전할 수 있는 양면 전략으로 작동합니다.

## 화면

| 경로 | 용도 |
| --- | --- |
| `/` | 메인 화면: 게임 시작하기, 게임 설명 |
| `/rules` | 카드 구성, 거래, 독점, 폭탄 규칙 안내 |
| `/setup` | 6~15명 플레이어 이름 일괄 등록, 제한시간 설정, 현재 규칙 확인 |
| `/host` | 교사 전용 운영 페이지: 공식 카드, 독점 현황, 연결, 판정, 로그 |
| `/board` | 학생 공개 전광판: 타이머, 시장 상태, 거래소 이용 가능 여부 |
| `/station` | 거래소 태블릿: A 명단 선택 → 카드 선택 → 화면 가리기 → B 명단 선택 → 거래 |

교사 운영 페이지에서 `학생 전광판 열기`를 누르면 새 창이 열립니다. 전광판은 거래 카드나 보유 카드를 표시하지 않습니다.

## 구현된 안정성

- 교사 Host가 유일한 공식 `GameState` 보유
- Station에는 공개 상태만 방송하고 본인 확인 팝업을 거친 뒤 해당 플레이어 카드만 일시 전달
- 플레이어 잠금, Version 낙관적 동시성, UUID TradeID 멱등 처리
- 서로 다른 플레이어 거래는 동시 허용, 같은 플레이어가 겹치면 두 번째 거래 거절
- 거래 중 연결 종료 후 같은 TradeID로 결과 회수
- 탭 전환 시 정상 연결을 강제로 끊지 않으며 실제 종료 시에만 재접속
- Host 상태 IndexedDB 백업 및 복원
- 거래 내역 실시간 기록, 결과 공개 후 최종 순위와 운영 로그를 함께 복사해 Excel·한글에 붙여넣기
- Game Logic / Network / UI 계층 분리 및 `IGameTransport` 기반 주입

## 실행

Node.js 20.19 이상 또는 22.12 이상에서 실행합니다.

```bash
npm install
npm run dev
```

다른 기기에서 접속할 때는 다음 명령을 사용합니다.

```bash
npm run dev -- --host
```

실기기 WebRTC는 HTTPS가 적용되는 Vercel 배포 환경에서 검증하는 것을 권장합니다.

## 검사

```bash
npm test
npm run build
```

자동검사는 6~15명 전 인원의 완전 배부와 덱 비율, 비공개 상태, 동일 장수 거래, 동시 거래, 플레이어 충돌, TradeID 중복, 복원 후 중복 방지, Version 충돌, 선택 세션 범위, 자원 독점, 폭탄 역독점, 시간 종료 순위를 검증합니다.

## Vercel 배포

GitHub 저장소를 Vercel에 연결하고 Framework Preset을 Vite로 선택합니다. Build Command는 `npm run build`, Output Directory는 `dist`입니다. 환경 변수는 필요하지 않습니다. `vercel.json`이 모든 직접 경로를 SPA 진입점으로 연결합니다.

## 현장 운영 권장 순서

1. `/setup`의 큰 입력창에 6~15명의 이름을 한 줄에 한 명씩 입력하고 제한시간을 설정합니다.
2. `/host`에서 거래소 QR을 태블릿 2~3대로 스캔합니다.
3. 모든 거래소가 연결된 것을 확인하고 학생 전광판을 프로젝터에 띄웁니다.
4. 학생은 거래소 명단에서 본인 이름을 선택하고 경고 팝업을 확인한 뒤 카드를 고릅니다.
5. 독점 발생 시 게임과 거래소가 자동으로 멈춘 것을 확인한 뒤 `결과 공개`를 누릅니다.
6. `복사하기`로 최종 결과와 운영 로그를 Excel·한글에 붙여넣습니다.

현재 디자인은 교체 가능한 Placeholder UI입니다. 추후 이미지, 배경, 카드 아트, 효과음, BGM, 애니메이션을 추가해도 게임 엔진과 WebRTC 구조를 변경하지 않도록 구성했습니다.
